# 评审速览：6 阶段融合体系一页纸（定稿版）

> 状态：**已定稿 V2.4**（2026-08-17；V2.1~V2.4 = 四轮独立评审修订，详见 `00-总览` 变更记录）
> 用途：快速回忆与索引——本页摘要 + 00-总览是权威。

## 一句话结论

**立项（调研+初设+总框架）→ 详细设计（100% 完美施工图 + 5% 瑕疵处置）→ 实施（拆分+契约+分包+验收+多线）→ 组装（联调+总验收+整改）→ 竣工（签字+竣工图+上线）→ 运维（监控+闭环+复盘）**，变更管理与缺陷闭环贯穿全程。

## 每阶段一页摘要

| 阶段 | 核心 | 关键强化 |
|:---|:---|:---|
| 1 立项 | 目标确认卡（止损线+触发动作）、先查后造、选型 2~3 候选拍板留档、PoC=最小验证、规模预判、总框架（PRD+契约骨架+评测基线） | 双明确是阶段 2 准入前提 |
| 2 详细设计 | **100% 完美施工图**（主体框架/功能/装饰美观三方面）；七要素任务图；零思考走查；冻结 | 走查**跨模型/跨工具**；美观设计人工评审；5% 瑕疵处置（A/B/C 三级，B≥3 次升 A） |
| 3 实施 | 拆分六规则（施工图分册）；任务包级契约（**不改编号**）；照图施工七纪律；分包验收（P0 100% + 性能预算）；多线管理（状态门+灯+自动评测+止损线对账） | 数据链路明示；并行度受控；四级连锁勾销；**变更三级分级**；总控独占写权 |
| 4 组装 | 模块化连接三层保障（schema→契约测试→端到端）；逐环联调不新增功能；总验收（查漏项/蔓延）；整改（缺陷闭环） | 总验收结论在本阶段，签字在阶段 5 |
| 5 竣工 | 压测、安全审查、签字、竣工图（实际快照）、回滚预案、上线 | 竣工图=运维对比原点 |
| 6 运维 | 三维监控、漂移、badcase 持续闭环、数据回流、定期评测、**复盘入库** | 闭环回起点：反哺下一项目立项 |

## 三条贯穿暗线

1. 状态门 + 进度总览（只认证据）
2. 变更通道（V2.1 三级分级：登记免确认/轻评审/实时确认；四级连锁勾销）
3. 文档即事实源（索引与归档约定）

## 大模型适配性

文档驱动分步执行 / 外部记忆 / 输出必须验证 / 上下文小而专 / 人机分工 / 最小验证先行。适配所有通用大模型（触发线与包粒度按模型能力调）；执行载体四选一除「真新会话」外是 DSH 能力。
